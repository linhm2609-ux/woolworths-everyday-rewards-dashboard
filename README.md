Woolworths Everyday Rewards Dashboard

Power BI dashboard on Woolworths Everyday Rewards loyalty data: KPIs, location insights and key-influencer analysis.

Portfolio project. Woolworths branding is used for illustration only; this project is not affiliated with or endorsed by Woolworths.

Business questions
How is the loyalty programme performing overall (transactions, points earned and redeemed)?
How does loyalty activity differ across store locations?
What influences how many points members redeem (for example points earned or the type of redemption)?
Report pages
Page	What it shows	Main visuals
Overview	Headline loyalty KPIs and trends	KPI cards, line charts, donut and pie charts, treemap, scatter chart, clustered bar chart, slicer
Location Insights	How performance differs by location	KPI visual and cards, decomposition tree, clustered bar charts, line chart, slicer
Key Influence	What drives the number of points redeemed	Key influencers visual, slicer
Key findings
Overall: 105.5K transactions and 772K points redeemed; 5.18% of transactions include a redemption.
Location (Chatswood): points redeemed are 2.39% of points earned, below the 2.48% threshold (-3.76%). Chatswood contributes 9.18% of all points earned but only 8.84% of all points redeemed.
Redemption mix (Chatswood): of 68,274 points redeemed, 92.6% come from Active members. Within Active members, Shopping Discount makes up 66%, Fuel Discount 23%, Qantas Points 6% and Donation 4%.
Key influencers: the strongest driver of points redeemed is points earned. When the sum of points earned is more than 45, average points redeemed is about 148, which is +63.32 points vs. the average of 84.36 for everything else.
Interpretation: members who earn more points have more to redeem, so this shows association, not cause.
